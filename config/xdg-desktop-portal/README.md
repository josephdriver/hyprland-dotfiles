# XDG Desktop Portal Notes

Sprint 01 does not ship a custom portal config yet.

Reason:
- Hyprland already provides `xdg-desktop-portal-hyprland`
- CachyOS defaults may already be good enough
- hard-coding portal preference too early can make debugging harder

Validation targets for this sprint:
- portal service starts in the user session
- file picker works in a portal-aware application
- screen sharing works in a portal-aware application

Do not add theme-related portal changes in Sprint 01.
